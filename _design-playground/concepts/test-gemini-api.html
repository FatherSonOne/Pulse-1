🔑 Gemini API Key Diagnostic Tool

📋 Instructions

This tool tests your Gemini API key configuration. It checks:

  1. If API key is saved in browser localStorage
  2. If the API key actually works by making a test API call

Note: Environment variables (VITE_GEMINI_API_KEY) can only be checked when running through the Pulse app itself.
