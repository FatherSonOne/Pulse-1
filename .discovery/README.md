# Discovery Questions

This folder stores all questions that are asked during development and decision-making processes for quick reference and finding.

## Purpose

- Track questions that need answers
- Store decision-making discussions
- Enable quick search and retrieval of past inquiries
- Document the discovery process

## Structure

- `questions.jsonl` - Main questions log (JSONL format for easy parsing)
- Each line is a JSON object with: timestamp, question, context, tags, status, answer

## Usage

Questions are automatically logged here during your interactions. You can search through this folder to find past questions and their contexts.
